# Work Time Manager

ローカルPCだけで使う、業務時間・タスク時間管理Webアプリです。

クローン後の詳しい手順は **[実行手順書（SETUP.md）](SETUP.md)** を参照してください。準備・起動・停止・バックアップ・更新・トラブル対応をまとめています。

## 主な機能

- 当日の開始時間 / 休憩開始 / 休憩終了 / 終了時間を入力し、実働時間を自動計算
- タスク名を登録してSQLiteへ永続保存
- 各タスクについて「何時から何時まで」を入力すると作業分数を自動計算
- 日付が変わるとトップ画面は新しい日の集計に切り替わるため、当日のタスク時間は0から開始
- タスク名は日付が変わっても消えず、手動削除するまで保持
- 登録済みタスク名の変更、本日の作業ログのタスク・内容・時刻の編集、タスク別小計の表示
- 過去の勤怠・作業ログは「履歴」画面で確認可能
- 23:30 → 00:15 のような日跨ぎ時間も計算可能
- タスクの作業内容を記録し、日付・タスクで履歴を絞り込み
- 入力一覧からタスクを削除しても作業履歴を保持（履歴内の記録削除は別操作）
- 日報の自動表示と日付別の追記保存・削除
- 独立したメモページで日付別メモと翌日以降も残る共通メモを保存
- 月曜〜日曜の週間勤怠・タスク時間集計
- 所要時間を「2時間 30分（150分）」の形式で表示
- 月・週・日のカレンダーで、予定と実施済みタスクを分けて表示
- 予定の追加・編集・削除（終日／同日内の時刻指定）
- 平日1日8時間超の残業と土日の全実働を別枠集計し、週・月の残業時間を表示

## 構成

- Python / Flask
- SQLite（Python標準 `sqlite3`）
- Jinja2
- HTML / CSS / Vanilla JavaScript

データベース `work_time.db` は初回起動時に自動作成されます。

## Windowsで起動

1. Python 3.10以降をインストール
2. このフォルダでコマンドプロンプトまたはPowerShellを開く
3. 以下を実行

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。

または `start.bat` をダブルクリックしてください。初回は仮想環境とFlaskを自動セットアップします（Python 3.10以降と初回のインターネット接続が必要です）。起動に失敗した場合は画面にエラーを残します。ブラウザが先に開いて接続できない場合は、サーバーの起動表示を待って再読み込みしてください。

日時は日本時間です。画面を開いたまま日付が変わった場合は15秒以内、または画面へ戻った際に再読み込みします。未保存の入力は失われるため日付が変わる前に保存してください。古い日付の画面からの勤怠・時間記録の保存は拒否します。

日跨ぎの作業は開始日の記録として全時間を集計します（23:30〜00:15は開始日に45分）。入力一覧のタスク削除では、過去の時間記録は残ります。履歴から作業記録自体を削除した場合は、その記録が合計・日報から除かれます。

## 日報・履歴・週集計

時間の記録時に任意の作業内容（2,000文字まで）を入力できます。同じタスクで違う内容を記録しても、タスクで履歴を絞り込めます。履歴は日付とタスクを同時に指定でき、該当した記録のある日だけを表示します。削除済みタスクも選択できます。同名で別に追加したタスクはIDで区別します。

「日報・週集計」で日付を選ぶと、その日の勤怠・タスク別合計・作業内容を表示します。成果や課題などの追記は日付別に保存できます。「追記を削除」は追記だけを削除し、勤怠とタスク記録は残します。日報の勤怠・タスク部分は元データから毎回集計され、固定されたスナップショットではありません。

週集計は選択した日が属する月曜〜日曜です。トップ画面では今週を表示します。実働・拘束時間の合計には開始と終了の揃った勤怠だけが含まれます。タスク時間は勤怠とは別に集計します。未完了の勤怠は件数を表示し、未入力の所要時間は `--` と表示します。

更新後の初回起動時に既存DBへ必要な列・テーブルを自動追加します。更新前にアプリを停止し、`work_time.db` をバックアップしてください。この更新以前にタスク削除で消えた記録は復元できません。

## カレンダーと残業時間

「カレンダー」の月表示では予定のみ、週表示では月曜〜日曜の予定・実施済みタスク・内容・時間、日表示では当日の予定・作業明細・タスク別時間と合計を表示します。予定はタスクや勤怠とは別に保存され、予定を登録しても作業実績や残業には加算されません。

予定のタイトルを押すと編集できます。日表示から予定を削除することもできます。開始・終了を両方空欄にすると終日扱いです。時刻を指定する場合は同日の開始より後の終了時刻を指定します。日跨ぎ・複数日の予定は日ごとに分けて登録してください。

残業はタスク時間ではなく、保存した勤怠の「勤務開始〜終了から休憩を引いた実働」を使用します。月〜金は勤怠を完了した各日を8時間基準とし、週内・月内それぞれで超過時間と不足時間を相殺します。相殺後の平日残業は0時間未満にはしません。土日は全実働を別枠として「＋○時間」と表示し、平日の不足時間とは相殺しません。平日の祝日もこのアプリでは平日として扱います。日跨ぎは開始日の曜日・月に全時間を集計します。未記録・未完了の勤怠は基準にも実働にも含めません。

週の残業は「一週間の業務時間」内に表示します。月の残業は「日報・週集計」の一番下に、選択日が属する月の平日・土日・合計と日別内訳を表示します。

休憩を登録する場合は勤務開始・終了の両方が必要です。休憩は勤務時間内の範囲のみ保存できます。フォームにはCSRF対策を適用しているため、アプリ再起動後は画面を再読み込みしてください。

## GitHub参考実装について

設計時に以下の公開リポジトリの構成・機能を比較しました。

- `sbj-ee/TimeLedger`: Flask + SQLite + Jinja2 + Vanilla JS。時間記録・プロジェクト管理・履歴という構成が今回に最も近い。
- `IssacSaleh/study-timer-and-task-tracker`: Flask + SQLiteでタスクを永続化し、時間セッションを別テーブルで管理する考え方が参考になる。
- `aurimas13/Time-Tracker`: Flask/Flask-SQLAlchemyベースで、タスクと実績時間を扱う比較的大きめの構成。

本アプリはこれらのコードをコピーしたものではなく、要件に合わせて新規実装しています。

## 空のデータベース

work_time.empty.db はテーブルのみを持つ初期化用ファイルです。勤務記録・タスク・メモは含みません。通常は起動時に work_time.db が自動作成されるためコピー不要です。手動で利用する場合はアプリ停止中に、既存の work_time.db がないことを確認してコピーし、work_time.db に名前を変更してください。既存データには上書きしないでください。
