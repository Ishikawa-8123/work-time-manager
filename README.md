# Work Time Manager

ローカルPCだけで使う、業務時間・タスク時間管理Webアプリです。

クローン後の詳しい手順は **[実行手順書（SETUP.md）](SETUP.md)** を参照してください。準備・起動・停止・バックアップ・更新・トラブル対応をまとめています。

## 主な機能

- 当日の開始時間 / 休憩開始 / 休憩終了 / 終了時間を入力し、実働時間を自動計算
- タスク名を登録してSQLiteへ永続保存
- 各タスクについて「何時から何時まで」を入力すると作業分数を自動計算
- 日付が変わるとトップ画面は新しい日の集計に切り替わるため、当日のタスク時間は0から開始
- タスク名は日付が変わっても消えず、手動削除するまで保持
- 過去の勤怠・作業ログは「履歴」画面で確認可能
- 23:30 → 00:15 のような日跨ぎ時間も計算可能

## 構成

- Python / Flask
- SQLite（Python標準 `sqlite3`）
- Jinja2
- HTML / CSS / Vanilla JavaScript

データベース `work_time.db` は初回起動時に自動作成されます。

## Windowsで起動

1. Python 3.10以降をインストール
2. このフォルダでコマンドプロンプトまたはPowerShellを開く
3. 以下を実行

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:5000 を開きます。

または `start.bat` をダブルクリックしてください。初回は仮想環境とFlaskを自動セットアップします（Python 3.10以降と初回のインターネット接続が必要です）。起動に失敗した場合は画面にエラーを残します。ブラウザが先に開いて接続できない場合は、サーバーの起動表示を待って再読み込みしてください。

日時は日本時間です。画面を開いたまま日付が変わった場合は15秒以内、または画面へ戻った際に再読み込みします。未保存の入力は失われるため日付が変わる前に保存してください。古い日付の画面からの勤怠・時間記録の保存は拒否します。

日跨ぎの作業は開始日の記録として全時間を集計します（23:30〜00:15は開始日に45分）。タスク削除は確認画面のとおり、そのタスクの過去の時間記録も削除します。

休憩を登録する場合は勤務開始・終了の両方が必要です。休憩は勤務時間内の範囲のみ保存できます。フォームにはCSRF対策を適用しているため、アプリ再起動後は画面を再読み込みしてください。

## GitHub参考実装について

設計時に以下の公開リポジトリの構成・機能を比較しました。

- `sbj-ee/TimeLedger`: Flask + SQLite + Jinja2 + Vanilla JS。時間記録・プロジェクト管理・履歴という構成が今回に最も近い。
- `IssacSaleh/study-timer-and-task-tracker`: Flask + SQLiteでタスクを永続化し、時間セッションを別テーブルで管理する考え方が参考になる。
- `aurimas13/Time-Tracker`: Flask/Flask-SQLAlchemyベースで、タスクと実績時間を扱う比較的大きめの構成。

本アプリはこれらのコードをコピーしたものではなく、要件に合わせて新規実装しています。

## 空のデータベース

work_time.empty.db はテーブルのみを持つ初期化用ファイルです。勤務記録・タスク・メモは含みません。通常は起動時に work_time.db が自動作成されるためコピー不要です。手動で利用する場合はアプリ停止中に、既存の work_time.db がないことを確認してコピーし、work_time.db に名前を変更してください。既存データには上書きしないでください。
